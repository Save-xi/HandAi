# AI 开发约定

1. 按 `docs/ai_roadmap.md` 推进项目书的 AI 部分：姿态、手势、时序预测、轻量化和评测。
2. 当前可运行基线是单右手；双手算法作为明确的后续任务开展。
3. 设备、Unity、5G、串口、SVH/AUBO 驱动由协作方负责；只保留输入输出适配入口。
4. AI 单帧算法集中在 `HandPipeline`，摄像头循环和离线评测共用它。
5. 保留模型维度、通道、采样率、数据值域、时序连续性检查；不要重新加入 SHA/AST 指纹、Git 身份、冻结收据和一次性运行限制。
6. 数据切分、validation 选型、真实误差与失败案例仍须如实记录。
7. 已有数据、checkpoint、机器报告和外部 Unity 工程保留；历史文档不是当前运行要求。
8. 注释、文档、日志、CLI 帮助默认中文；字段名和外部 API 保持必要英文。
9. 优先保持简单、可运行、可替换，避免把可选扩展变成 AI 启动前提。
