# AI 路线图

依据仓库根目录的 `项目.pdf` 第 3 节技术路线及第 4.1 节轻量化 AI 预测目标。你的工作集中在感知、预测、模型压缩和 AI 指标；设备、通信、Unity 与机械控制通过接口协作。

| 项目书内容 | 当前代码 | 下一步工作与交付物 |
|---|---|---|
| 3.1.1 RGB-D 图像输入 | 摄像头/视频输入；已有设备关键点入口 | 协作方提供图像/内参或标准 21 点；AI 侧只做坐标与数据适配 |
| 3.1.2 姿态估计，MediaPipe/MMPose 比较 | MediaPipe 和 FreiHAND 二维评测 | 接入一个 MMPose 对照，统一数据、输入分辨率、点顺序和计时范围 |

## 推进顺序

1. **姿态数据与对照。** 保留现有单右手作为可跑基线，补充遮挡、侧视、无手与出画样本。姿态模型共用 `HandDetection`；统一输出 21 点。InterHand2.6M 的单手/交互样本先用于检测评测，不自动变成双手控制。
2. **关键点时序预测。** 明确坐标系、归一化、采样率、历史窗口和预测时间距。以 hold-last、线性外推和现有 GRU 为比较起点，用同一分人/分视频切分评测。当前 9 通道模型继续作为代理任务参考，不把它称为已实现项目书的 21 点轨迹预测。
3. **数据域适配。** H2O 提供时序姿态；真实摄像头数据覆盖视角、遮挡和检测噪声。按人/会话划分训练、验证、测试，避免同一视频相邻帧落入不同集合。旧 subject4 和 V1–V7 已用于开发/诊断。
4. **轻量化与交付。** 根据协作方给出的目标运行环境选择导出格式。比较原模型、压缩模型的数值误差和推理耗时，交付权重、模型配置、调用样例。部署设备的驱动、Unity 和网络适配由对应成员完成。

## 指标如何对应项目书

| 目标 | AI 侧报告 |
|---|---|
| 验证集准确率 90% | 先明确“准确率”的定义；关键点任务报告 PCK、MPJPE、完整率，手势任务报告逐类 precision/recall/F1 与混淆矩阵 |
| 手部检测 ≤50 ms | 单独测检测器和手选择，报告 P50/P95、输入尺寸、硬件与批大小 |
| 总遥操作响应 ≤100 ms | AI 侧交付采集、检测、预测/输出时间；完整系统指标由各模块计时共同组成 |
| 轻量化预测 | 模型参数量/文件大小、FP32/量化误差、推理 P50/P95、预测收益与有效覆盖率 |

评测保留真实数据、配置、随机种子、误差及失败原因。文件哈希、干净 Git 工作区和一次性收据都不再是开发或评测前提。

## 本轮完成范围

本轮完成工程重构和 AI 接口整理。MMPose/Cascade R-CNN/ResNet-101 训练、InterHand2.6M 适配、21 点轨迹预测、ONNX/INT8 导出仍是后续算法工作，未在本轮实现。
